# 輔英科技大學 學生國內外獲獎紀錄管理、資料每週自動更新與領獎通知系統
**Fooyin University Student Awards Management, Weekly Auto-Update & Secure Award Portal**

---

## 一、 系統簡介與設計理念

本系統專為**輔英科技大學**設計，旨在全面結構化管理全校學生在**國際競賽、國內技藝學術競賽、體育賽事、專業技術證照及特殊優良事蹟**之獲獎紀錄與榮譽。系統全面支援：
1. **校務研究 (IR) 分析與評鑑專用報表**（支援 112 至 115 學年度上/下學期數據盤點與橫向學院對比）。
2. **智慧欄位校正引擎**：自動從「資料來源」（如 `113-3行政會議`、`114-6行政會議`）或「會議記錄時間 / 活動日期」推算正確之學年度與學期；若活動主辦單位無記錄則自動填寫為 **`無`**，並於最後一欄獨立呈現 **`資料來源`**。
3. **GitHub 掛網五層縱深個資保護架構**：符合台灣《個人資料保護法》，公開瀏覽預設採用去識別化遮罩，敏感個資以 **PBKDF2-SHA256 + AES-256-GCM** 端對端加密封裝，確保原始碼零明文個資外洩。
4. **學生領獎與獎助金通知系統**：包含 Email / LINE / 校園 Portal 領獎通知信派發、未申請催辦提醒與進度追蹤。

## 二、 學期、活動主辦單位與資料來源欄位規範

1. **學年度與學期自動推導規則 (`infer_year_and_semester`)**：
   - **由「資料來源」會議期別推算**：
     - 行政會議（如 `113-3行政會議`、`114-6行政會議`）：第 `1~5` 次（8月~1月召開）判定為 **`上`** 學期；第 `6` 次以上（2月~7月召開）判定為 **`下`** 學期，並同步對齊會議所屬學年度。
     - 校務會議（如 `115-2校務會議紀錄`）：第 `1~2` 次為 **`上`** 學期；第 `3` 次以上為 **`下`** 學期。
   - **由「會議記錄時間 / 活動日期」推算**：
     - `8月 ~ 1月` 歸屬 **`上`** 學期（8~12月學年度為 `西元年 - 1911`，1月為 `西元年 - 1912`）。
     - `2月 ~ 7月` 歸屬 **`下`** 學期（學年度為 `西元年 - 1912`）。
2. **活動主辦單位與資料來源分離**：
   - **活動主辦單位**：僅記錄實際賽事主辦機關；若會議紀錄或來源中無主辦單位紀錄，一律顯示並匯出為 **`無`**。
   - **資料來源**：獨立新增於清冊表格與匯出報表之**最後一個欄位**（例如：`115-3行政會議`、`校務會議紀錄`、`學校公開官方網站`、`112-114學年度填報資料`）。

## 三、 GitHub 掛網學生個資保密與資安設計

針對系統掛網於公開 GitHub / GitHub Pages 之資安風險，本系統實作五層防護：

1. **公開層預設去識別化 (`security_crypto.py`)**：
   - 學生姓名遮罩（如 `李○美`、`蔡○瑀、王○瑜`；原始未登載者如實顯示 `無`）、學號遮罩（如 `113****4`）、班級細項遮罩（`四技3年○班`）、原畢業學校隱藏（防止「系所+母校+姓氏」交叉比對識別），Google Drive 私密雲端佐證連結預設鎖定。
2. **PBKDF2-SHA256 + AES-256-GCM 驗證加密保險箱 (`embed_data.py`)**：
   - 敏感個資以 `PBKDF2-HMAC-SHA256`（150,000 次迭代 + 隨機 Salt）衍生 256-bit 金鑰，並透過 `AES-256-GCM`（隨機 96-bit Nonce）加密後存入 `web/data.js`。
   - 內建自動化 **零明文個資外洩稽核 (Zero-Plaintext PII Audit)**：若偵測到任何未遮罩姓名或學號將自動阻斷建置。
3. **瀏覽器 WebCrypto 記憶體解密與閒置自動上鎖 (`web/app.js`)**：
   - 管理員點選右上角「**個資保護中 (管理員解鎖)**」輸入通行密碼後，僅於瀏覽器揮發性記憶體（RAM）內透過原生 Web Crypto API 解密，**絕不寫入 LocalStorage 或 Cookie**。
   - 具備 **10 分鐘閒置自動上鎖** 倒數計時器與密碼錯誤防暴力破解延遲機制。
4. **GitHub Actions 隔離部署與防爬蟲 / 防 XSS (`.github/workflows/deploy.yml`, `web/index.html`)**：
   - GitHub Actions 僅發布 `./web` 靜態目錄，並在部署前自動掃描阻擋任何 `.json`、`.csv`、`.xls`、`.py` 原始檔外流至網站伺服器。
   - 網頁內建嚴格 `Content-Security-Policy (CSP)`、全面 HTML 跳脫防範 XSS，以及 `robots.txt` 與 `noindex, nofollow, noarchive` 阻絕搜尋引擎與 AI 爬蟲收錄。
5. **原始個資檔 `.gitignore` 保護**：
   - 本機原始檔 `fooyin_student_awards_standardized.json`、`.csv`、`*.xls`、`*.xlsx` 已列入 `.gitignore`。
   - **重要提醒**：若您過去曾將原始 `.json` / `.csv` / `.xls` 提交至 GitHub 歷史紀錄，請於上傳前執行以下指令將其自遠端追蹤移除（本機檔案會完整保留）：
     ```bash
     git rm --cached fooyin_student_awards_standardized.json fooyin_student_awards_standardized.csv 112-114學年度填報資料.xls
     ```

## 四、 操作使用指南

### 1. 產出安全加密之 GitHub 掛網前端資料 (`data.js`)
```bash
# 使用自訂高強度管理員密碼加密封裝 (建議正式掛網前變更密碼)
python embed_data.py --passphrase "您的自訂管理員高強度密碼"
python copy_to_root.py

# 若希望公開站台完全不包含加密保險箱 (純公開去識別化模式)
python embed_data.py --public-only
python copy_to_root.py
```

### 2. 啟動本機安全管理伺服器
```bash
# 預設僅綁定本機 127.0.0.1:8000，阻絕區網未授權連線
python run_system.py
```

### 3. 三大來源 LOOK 檢視與每週自動更新 (`schedule_updater.py` & `sources_config.json`)
- **三大自動監看來源**：
  1. **個人雲端硬碟 / `行政會議` 檔案夾**：支援本機同步目錄（`./行政會議`、`G:/我的雲端硬碟/行政會議`）、雲端試算表 CSV 連結，以及於網頁端直接選取整個 `行政會議` 資料夾批次掃描匯入。
  2. **學校公開網頁**：自動掃描輔英官網焦點新聞與秘書室會議公開專區。
  3. **系上公開網頁**：自動掃描各學院系所榮譽榜（支援於網頁介面動態新增/移除系網網址與一鍵 `LOOK` 開啟檢視）。
- **雙軌每週自動排程（每週一 08:00）**：
  - **GitHub 雲端排程**：`.github/workflows/weekly_update.yml` 每週一台灣時間 08:00 自動執行並更新去識別化加密資料。
  - **Windows 本機排程**：雙擊 `run_weekly_update.bat` 立即更新，或執行 `python schedule_updater.py --install-windows-task` 註冊每週一自動排程。

### 4. 100% 對稱雙向匯出與匯入機制
- 本系統匯出之 `.xlsx`、`.csv`、`.json`（包含「完整管理清冊」與「112-114 填報格式」，最後一欄皆為 `資料來源`）與匯入格式 **100% 欄位對稱一致**：匯出檔案修改或新增資料列後可**原檔直接匯入**（既有識別號自動同步更新異動欄位、空白或新識別號自動新增入庫）。

### 5. 命令列管理與匯出工具
```bash
# 執行全資料庫學期、活動主辦單位與資料來源標準化校正
python awards_system.py --normalize-db

# 產出校務研究 (IR) 統計報表 (含各學年度上/下學期分佈)
python awards_system.py --report

# 匯出去識別化公開安全版 CSV 清冊 (最後一欄為資料來源)
python awards_system.py --export 輔英獲獎公開清冊.csv --public-export
```
