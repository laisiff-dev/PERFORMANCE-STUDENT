# 輔英科技大學 學生國內外獲獎紀錄管理、資料每週自動更新與領獎通知系統
**Fooyin University Student Awards Management, Weekly Auto-Update & Award Notification System**

---

## 一、 系統簡介與設計理念

本系統專為**輔英科技大學**設計，旨在全面結構化管理全校學生在**國際競賽、國內技藝學術競賽、體育賽事、專業技術證照及特殊優良事蹟**之獲獎紀錄與榮譽。系統全面支援：
1. **校務研究 (IR) 分析與評鑑專用報表**（支援 113 至 115 學年度數據盤點與橫向學院對比）。
2. **每週自動更新機制**：定期爬抓與解析輔英科技大學行政會議紀錄、校務會議紀錄及公開官網新聞。
3. **學生領獎與獎助金通知系統**：包含 Email/LINE/校園 Portal 領獎通知信派發、線上數位簽領與獎助金發放進度追蹤。
4. **多格式資料匯出引擎**：支援一鍵匯出 Excel (`.xlsx`)、UTF-8 with BOM CSV 及 JSON 格式資料庫。

## 三、 資料庫欄位定義與抬頭標準

本系統嚴格遵循繁體中文標準命名與欄位規範：

| 欄位抬頭名稱 | 資料類型 | 說明與範例 |
| :--- | :--- | :--- |
| **編號** | 數值 | 系統唯一流水號（`#1` 至 `#485`） |
| **學年度** | 文字 | 獲獎所屬學年度（如：`113學年度`、`114學年度`、`115學年度`） |
| **資料來源** | 文字 | 提案會議或公開管道（如：`115-4行政會議`、`學校公開官方網站`） |
| **所屬學院** | 文字 | 護理學院、醫學與健康學院、環境與生命學院、人文與管理學院、跨學院/校隊 |
| **系所名稱** | 文字 | 獲獎學生就讀系所（如：護理系、醫學檢驗生物技術系、環境工程與科學系） |
| **學制班級** | 文字 | 學制與班級（如：四技3年1班、五專5年1班、碩士班1年級） |
| **獲獎學生** | 文字 | 獲獎學生姓名（多人以頓號分隔） |
| **學生學號** | 文字 | 獲獎學生學號（用於領獎與發放身分核對，如：`11440123`） |
| **指導老師** | 文字 | 專案指導教授、指導老師或教練 |
| **競賽層級** | 文字 | 五大分類：`國際競賽`、`國內競賽`、`體育競賽`、`專業證照`、`特殊優良事蹟` |
| **競賽或活動名稱**| 文字 | 正式賽事名稱（如：2026倫敦國際發明展、全國大專校院運動會） |
| **參賽項目或作品名稱**| 文字 | 競賽組別或研發作品題目（如：智慧型室內CO₂捕集與探測系統） |
| **榮譽獎項** | 文字 | 所獲得獎項（如：金牌、第一名、冠軍、亞軍、特優、入圍） |
| **獎助金金額** | 數值 | 學校頒發之獎助學金金額（新臺幣 NTD，如：`15000`） |
| **發放與領獎狀態** | 文字 | `待通知`、`通知已發送`、`已線上簽領`、`已完成撥款` |
| **通知時間** | 日期 | 領獎通知信派發日期（如：`2026-09-18`） |
| **領獎截止日期** | 日期 | 學生完成線上簽領或補件之截止日 |
| **原畢業學校** | 文字 | 學生入學前母校（用於招生來源追蹤與精準分析） |
| **佐證連結** | 文字 | 雲端原始佐證連結或官方新聞發布網址 |
| **備註** | 文字 | 特殊獲獎背景或效益註記 |

## 四、 核心功能特色說明

### 1. 每週自動更新管道 (`schedule_updater.py`)
- **會議紀錄抓取**：自動排程對輔英科技大學 **行政會議紀錄、校務會議紀錄與官網最新公告** 進行內文解析與抓取。
- **差分比對與去重**：依據「獲獎學生 + 賽事名稱 + 學年度」唯一鍵進行重複性校對，避免重複入庫。
- **背景服務與手動觸發**：支援 `python schedule_updater.py --run-now` 立即抓取，或 `--schedule` 啟動每週一 08:00 自動執行。

### 2. 學生領獎與獎助金通知系統 (`notification_service.py`)
- **多管道個人化通知書**：自動生成包含學生姓名、學號、獲得獎項、金額與截止日之 Email / LINE Notify / 輔英校園 Portal 格式通知。
- **數位簽領生命周期**：狀態從 `待通知` -> `通知已發送` -> `已線上簽領` -> `已完成撥款` 完整追蹤。
- **一鍵批量通知**：可在 Web 管理介面上點擊「批量發送領獎通知」，自動為所有待領獎學生寄出憑證信件。

### 3. 多元格式匯出引擎 (`awards_system.py`)
- 提供符合教育部訪視評鑑及校務研究 (IR) 格式之 Excel (`.xlsx`) 與 UTF-8 with BOM CSV 下載，解決中文亂碼問題。

### 4. 現代化 Web 視覺化管理 Portal (`web/index.html`)
- **KPI 數據指標卡**：即時顯示全校獲獎總數、國際競賽比例、總獎助金金額與待領獎通知數。
- **Chart.js 動態統計圖表**：學院橫向對比圖、競賽層級圓餅圖、領獎狀態長條圖。
- **多維度複合篩選器**：學年度、學院-系所連動選單、競賽層級、領獎狀態及全文檢索。

## 五、 操作使用指南

### 1. 啟動 Web 視覺化查詢與管理系統
在終端機執行：
```bash
python run_system.py
```
或直接在瀏覽器開啟 `web/index.html` 進行離線操作！

### 2. 執行 Python 命令列管理與統計分析
- **產出全校校務研究 (IR) 統計報表**：
  ```bash
  python awards_system.py --report
  ```
- **執行每週會議紀錄與官網抓取更新**：
  ```bash
  python schedule_updater.py --run-now
  ```
- **測試發送單筆學生領獎通知**：
  ```bash
  python notification_service.py --test-notify 1
  ```
- **匯出全校獲獎與領獎清冊為 Excel / CSV**：
  ```bash
  python awards_system.py --export 輔英獲獎清冊.csv
  ```
