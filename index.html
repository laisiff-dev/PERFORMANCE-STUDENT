學生個資保密與 GitHub 掛網安全管理中心

本系統五層縱深個資保護架構 (符合台灣個人資料保護法)

  • 1. 公開層預設去識別化：data.js 公開資料僅保留遮罩姓名（如 陳○婷）、遮罩學號（111****1）與隱藏原畢業學校，杜絕交叉比對識別。
  • 2. AES-256-GCM 端對端加密保險箱：敏感個資採用 PBKDF2-SHA256 (150,000 次迭代) 衍生金鑰與 AES-256-GCM 驗證加密，前端原始碼無任何明文個資或密碼雜湊。
  • 3. 記憶體暫存不落地 & 閒置自動上鎖：解鎖後僅暫存於瀏覽器揮發性記憶體（絕不寫入 Cookie 或 LocalStorage），閒置 10 分鐘自動清除金鑰並恢復遮罩。
  • 4. GitHub 部署隔離與防爬蟲：GitHub Actions 僅發布靜態前端並屏蔽 .json/.csv/.xls 原始檔，搭配 noindex 與嚴格 CSP 阻絕搜尋引擎收錄與 XSS 攻擊。
  • 5. 雙模式匯出與權限管控：未解鎖狀態僅允許匯出去識別化公開資料，領獎催辦通知與完整個資匯出均受授權保護。
